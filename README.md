# 🏦 Retail Banking Customer Analytics

An end-to-end data analytics project focused on understanding **customer activity, transaction behavior, investment patterns, and branch performance** in a retail banking environment.

## 🎯 Business Problem

The goal was to understand customer activity patterns, identify inactive customers, analyze transaction and investment behavior, and compare regional/branch performance.

## 🛠️ Tech Stack

* **MySQL** — Data cleaning, validation & SQL analysis
* **Excel** — Exploratory analysis, calculations & validation
* **Power BI** — Data modeling, DAX, KPIs & interactive dashboards

## 📊 Data

The project uses three datasets:

* **Customer Data** — Customer demographics and segmentation
* **Transaction Data** — Transactions, balances, accounts & investments
* **Bank Data** — Branch revenue, expenses & profit margin

## 🔍 Key Analysis

* Customer activity and segmentation
* Transaction volume and transaction value
* Investment behavior by customer and investment type
* City and regional performance
* Branch revenue, expenses and profitability
* Investigation of inactive customer behavior

## 💡 Key Insights

* **6,335 customers** had recorded transaction activity.
* **Employee customers** had the highest number of inactive customers, while many still maintained investment activity.
* Further investigation showed that many inactive Employee customers had **previously regular transaction activity that gradually declined**.
* **South** recorded the highest revenue, **East** the highest expenses, and **North** the highest average profit margin.

**Data → Finding → Hypothesis → Evidence → Conclusion → Business Meaning**

The project focused not only on reporting numbers, but on investigating **why** patterns occurred and translating findings into business insights.
